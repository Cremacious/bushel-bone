# First-Run Tutorial Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Add the opt-in, in-context tutorial to the prototype: Reuben introduces himself on the first run, and in guided mode tips lean in from the Ask Reuben bar (highlighting the control they explain) on first encounter of each mechanic.

**Architecture:** A small `tutorial` unit inside the existing prototype IIFE. State is two `localStorage` flags (`bb_seenIntro`, `bb_guided`) plus a per-run `S.tutShown`. A single `tip(id, text, selector)` function decides whether to show, renders the tip in the Ask Reuben bar (or, when an overlay is open, at the top of that overlay), and rings the target control. Seven one-line call sites fire the tips. Reuses the Ask Reuben bar, the overlay system, and the palette from the Foreman feature.

**Tech Stack:** Single-file HTML/CSS/JS (`prototype/year1.html`), tested with Vitest + jsdom. Source of truth: `docs/superpowers/specs/2026-07-25-tutorial-design.md`. All player text obeys the no-dash rule.

**Branch:** create `feat/tutorial` off `main` before Task 1.

```js
export function boot(opts = {}) {
  const { seenIntro = true, guided = false } = opts;
  const html = readFileSync(htmlPath, "utf8");
  const full = "<!doctype html><html><head></head><body>" + html + "</body></html>";
  const dom = new JSDOM(full, {
    runScripts: "dangerously",
    pretendToBeVisual: true,
    url: "http://localhost/",
    beforeParse(window) {
      try {
        if (seenIntro) window.localStorage.setItem("bb_seenIntro", "1");
        window.localStorage.setItem("bb_guided", guided ? "1" : "0");
      } catch (e) {}
    },
  });
  const win = dom.window;
  const doc = win.document;
  const T = win.__BB_TEST__;
  if (!T) throw new Error("window.__BB_TEST__ hook missing");
  return { dom, win, doc, T };
}
```

- [ ] **Step 5: Add the JS** inside the IIFE:
```js
  let tutHi = [];
  function tip(id, text, selector){
    if(!tutGuided()) return;
    if(!S.tutShown) S.tutShown = {};
    if(S.tutShown[id]) return;
    S.tutShown[id] = true;
    const body = '<div class="tut-tip"><div class="who"><span class="rdot"></span> Reuben</div><p>'+text+'</p><button class="got" id="tut-got">Got it</button></div>';
    const overlayOn = document.getElementById("overlay").classList.contains("on");
    if(overlayOn){
      document.getElementById("overlay-panel").insertAdjacentHTML("afterbegin", body);
    } else {
      const tb = document.getElementById("tipbar"); tb.innerHTML = body; tb.classList.add("on");
    }
    if(selector){ document.querySelectorAll(selector).forEach(el=>{ el.classList.add("tut-highlight"); tutHi.push(el); }); }
    const got = document.getElementById("tut-got");
    if(got) got.addEventListener("click", dismissTip);
  }
  function dismissTip(){
    const tb = document.getElementById("tipbar"); if(tb){ tb.classList.remove("on"); tb.innerHTML=""; }
    const t = document.querySelector("#overlay-panel .tut-tip"); if(t) t.remove();
    tutHi.forEach(el=>el.classList.remove("tut-highlight")); tutHi = [];
  }
  function replayTips(){ if(S) S.tutShown = {}; tutSetGuided(true); }
```

- [ ] **Step 1: Create `prototype/tests/tutorial-flow.test.mjs`:**

```js
import { describe, it, expect } from "vitest";
import { boot, advance } from "./helpers.mjs";

describe("tutorial flow", () => {
  it("plays a full guided year to an end screen without blocking", () => {
    const { doc } = boot({ seenIntro: true, guided: true });
    let steps = 0;
    while (advance(doc) && steps < 400) steps++;
    expect(steps).toBeLessThan(400);
    expect(doc.getElementById("again")).toBeTruthy();
  });

  it("fires the planting tip on the first planting screen", () => {
    const { doc, T } = boot({ seenIntro: true, guided: true });
    // advance until the planting screen shows a tip
    let steps = 0, saw = false;
    while (steps < 40) {
      if (T.getState().tutShown && T.getState().tutShown.plant) { saw = true; break; }
      if (!advance(doc)) break;
      steps++;
    }
    expect(saw).toBe(true);
  });

  it("the Ask Reuben panel offers to stop the tips", () => {
    const { doc, T } = boot({ seenIntro: true, guided: true });
    T.openAskReuben();
    expect(doc.getElementById("overlay-panel").textContent.toLowerCase()).toContain("tips");
  });
});
```
